# Dinesh Kumar · AI/ML Engineer portfolio

A cinematic, light-themed portfolio built with React and React Three Fiber. One persistent
WebGL canvas sits behind the page; scrolling moves the camera through a storyboard:

1. **Loader**: 0→100 counter, "DK" drawn as a line, wipe into the hero
2. **Hero**: a sky world of portals and floating islands (an animated image), with the glass AI core floating in the main portal
3. **About**: the core opens into a neural network with light pulses on its connections
4. **Skills**: the nodes regroup into six skill orbits with 3D labels
5. **Work**: the camera flies past the five project covers as curved glass panels
6. **Experience**: a glowing timeline that lights up as you pass each role
7. **Contact**: everything settles into a ring of light around the core

Each project has a recruiter-focused case study at `/projects/:slug`.

## Edit the content

**Every word, number, link and image path lives in [`src/data/content.ts`](src/data/content.ts).**

Anything written as `[TODO: …]` is a note to you and is **never shown on the site**: the UI strips
TODO markers and hides any line, chip, link or meta field that is only a TODO. Replace a TODO with
the real value and it appears automatically.

| What | Where |
| --- | --- |
| Name, headline, contact links | `person`, `contact` |
| Impact strip, About, Skills, Experience | `impactAtAGlance`, `about`, `skills`, `experience` |
| Case studies (order = home page order) | `projects` |
| Project images (WebP, max 1600px) | `public/projects/` |
| Resume PDF | `public/resume.pdf` |
| Open Graph image, favicon | `public/og-image.png`, `public/favicon.svg` |

## Run it

Requires Node 18+.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build into dist/
npm run preview    # serve dist/ at http://localhost:4173
```

`npm run build` also writes one HTML file per case study with its own title, description and
Open Graph tags (so link previews work without JavaScript), plus `404.html`, `sitemap.xml` and
`robots.txt`.

## Deploy (Vercel)

Project → Settings → **Build & Development Settings**:

- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install` (default)

`vercel.json` already contains the same settings plus the rewrites that make `/projects/*`
work on refresh. Push to the branch Vercel deploys from (or merge `ai-ml-portfolio` into it).

## How it is built

- **Vite + React 18 + TypeScript**, `react-router-dom` for `/projects/:slug`
- **three**, **@react-three/fiber 8**, **@react-three/drei 9**, **@react-three/postprocessing 2**
- **GSAP + ScrollTrigger** and **Lenis** for smooth scrolling, **framer-motion** for UI and page transitions

```
src/
  data/content.ts        all content
  pages/                 Home, CaseStudy (code-split), NotFound
  components/            navbar, cursor, loader, contact, lightbox, diagrams…
  three/                 the 3D scene
    timeline.ts          scroll → storyboard value t, camera spline keyframes
    HomeWorld.tsx        core rig, camera rig, staged mounting
    Core.tsx Network.tsx Gallery.tsx Timeline.tsx Particles.tsx
    AccentWorld.tsx      the small tinted glass object on case-study pages
    Capture.tsx          dev-only pages used to render the static images
  styles/                global.css, case.css
```

### Performance and accessibility

- The 3D bundle is lazy-loaded after first paint. It mounts over several frames so shader
  compilation doesn't block the page, and pauses when the tab is hidden.
- `PerformanceMonitor` + `AdaptiveDpr` (DPR capped at 1.75) drop to a cheaper glass material and
  no depth of field when the frame rate falls.
- **Phones (<768px):** core and particles only. No transmission material, no post-processing.
- **No WebGL, or `prefers-reduced-motion`:** no canvas. A static render of the core
  (`public/hero/static-desktop.webp`, `static-mobile.webp`) is the hero image and scrolling is native. All content is real HTML.
- For testing, add `?nowebgl` or `?reducedmotion` to any URL to force the fallback.

### The hero sky world

The hero background is one image (`design/hero/source.png`) brought to life in a full-screen shader
(`src/three/HeroBackdrop.tsx`): depth parallax on mouse and scroll, boiling clouds, bobbing floating
islands, flowing waterfalls, light pulses running towards the portal, a shimmering portal, and a
light haze so the text stays readable. Scrolling dollies into the portal and fades into the page.

Its assets in `public/hero/` are generated by `design/hero/build_hero_assets.py` (islands cut out,
depth / glow / waterfall maps). To change the image, replace `source.png`, adjust the coordinates
at the top of the script and in `src/three/heroLayout.ts`, then run:

```bash
pip install numpy pillow opencv-python-headless scipy
python design/hero/build_hero_assets.py
```

### Re-rendering the static images

With `npm run dev` running, these dev-only pages render the assets:

- `/__capture/hero`: the hero scene at rest (canvas at 1440×900 and 390×844 → `public/hero/static-*.webp`)
- `/__capture/core`: the core on its own
- `/__capture/og`: the 1200×630 Open Graph card (→ `public/og-image.png`)
